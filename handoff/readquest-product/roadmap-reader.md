# ReadQuest — roadmap читалки после теста (Продукт, [дата снята].2026)

Источник: задание Джессики от [дата снята] (п. 3, референсы ReadEra и Moon+ Reader).
Правило: в сборку до теста и во время теста ничего из этого не берём — сначала стабильный рендер, потом фичи. Порядок может поменяться по интервью (вопрос 8 гайда: «что раздражало в читалке»).

## v1 — первые после теста (дешёвые, не трогают рендер)
1. **Оглавление (главы) с переходом.** pdf.js `getOutline()`, для текста — заголовки из FB2/EPUB. Отдельная шторка, рендер страницы не трогает. Для целевой аудитории с академическими PDF это главная навигационная боль.
2. **Тема день/ночь** (и сепия). Вечернее чтение = основное окно для привычки «10 минут в день». Для текста — CSS-палитра, для PDF — фильтр поверх готового холста, без перерендера.

## v1.1
3. **Закладки** (тап в правом верхнем углу + список). Простые, данные — отдельное поле книги в `library`, Архитектору согласовать схему.
4. **Поиск по тексту** с подсветкой и навигацией. Для PDF — текстовый слой pdf.js; тяжелее, нужен индекс.
5. **Вертикальный скролл для PDF.** Самое ценное по ReadEra, но это новый режим рендера (непрерывная лента страниц) — только после того, как постраничный режим прожил тест без `pdf_stall_recovered`.
6. **Поля страниц / одноколоночный режим** для текста.

## v2
7. **Миниатюры страниц** (сетка). Дорого по памяти на телефоне, нужен кэш превью.
8. **Настраиваемый ридербар** (какие кнопки показывать). Интерфейс рисует заранее.
9. **Жесты-шорткаты:** яркость по левому краю, день/ночь в левом верхнем углу. Конфликтуют с тапами листания — только после UX-проверки.

## Позже / под вопросом
10. **Автопрокрутка и RSVP (скорочтение).** Ломают учёт минут: при автопрокрутке минуты идут без перелистываний и без внимания человека, это обход потолка 3 мин/стр и метрики «пустых» сессий. Берём только с отдельными правилами начисления (Квестмастер + Архитектор), и не раньше, чем метрика подтвердится.
11. **Блокировка ориентации/экрана** — мелочь, по запросам тестеров.

## Что уже закрыто сборкой 481e067 (п. 1, 2, 4 задания)
Двойная буферизация, один родитель трансформации для подложки/холста/текста, зум через transform с рендером после жеста, без нулевого вьюпорта при fullscreen/resize, номер страницы из меток PDF. Проверяем на телефоне после выкладки.

## После этапа 0 (Продукт, 08.10.2026), в этап 2
- `persistPage()`: маленький ключ на книгу вместо перезаписи всего `rq_v1` (решение Босса; при 390 КБ рывок 47 мс на ×6).
- Позиция чтения: открывать и показывать на экране старого окна текущую страницу, а не самую дальнюю (`maxRatio`). Сейчас, если человек вернулся перечитать стр. 10 при максимуме 50, книга откроется на 50.
- `idb.js`: одно соединение на запуск вместо нового на каждую операцию; `save()` не переписывает тексты всех книг.
