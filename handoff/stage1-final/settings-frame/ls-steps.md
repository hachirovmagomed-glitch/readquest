# Расстояние между буквами: ступени ↔ `rq_set.ls` (1г, Интерфейс, 12.10.2026)

Источник: `source/js/reader.js`. `SETDEF.ls = 0`; кнопки `lsMinus`/`lsPlus` меняют на 0,5 в диапазоне −1…3 (px); применяется как `letterSpacing = ls + 'px'`.
Новых полей нет, `schemaVersion` не трогаем.

| Подпись | Пишем в `ls` при нажатии | Показываем этой ступенью, если в `ls` лежит |
|---|---|---|
| уже | −0,5 | ls < −0,25 (то есть −1 и −0,5) |
| обычное | 0 (по умолчанию) | −0,25 ≤ ls ≤ 0,25 (то есть 0; а также пусто/`null` → 0) |
| шире | 0,5 | ls > 0,25 (то есть 0,5 … 3) |

Правило: промежуточное или старое число (−1, 1, 1,5 … 3) **показываем ближайшей ступенью и не переписываем**. `ls` меняется только когда человек сам нажал ступень. Импорт старых данных с `ls` из −1…3 проходит как есть.
Почему ±0,5, а не ±1: при 19 px Georgia +1 px уже заметно разрежает кириллицу, а −1 px слипает «ш/щ/м»; ±0,5 видно глазом и читаемо. Ничьих при шаге 0,5 нет.

Толщина шрифта (то же правило): тоньше = `weight` 300, обычная = 400, жирнее = 600 — значения уже есть в `reader.js` (`wLight/wNorm/wBold`).

## Уточнения Архитектора (12.10)
- Уже лежащие −1, 1, 1,5 показываем «уже»/«шире» и не переписываем, пока человек сам не нажмёт ступень; после нажатия значение ровно −0,5 / 0 / 0,5.
- Границы: −0,25 и 0,25 → «обычное»; толщина 450 и 500 → «обычная».
- Отображение — одна функция, закрытая тестом, не в разметке.
