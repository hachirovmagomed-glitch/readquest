# Архитектор: заметки (свежее сверху)

## 2026-10-09 — контракт темы (скины в самом конце очереди)
- Тема = полный набор `--rq-*` по обязательному списку из `handoff/stage1-final/tokens.json`. Нет токена в теме → базовый (страховка в приложении).
- Скин: `<html data-skin="…">`, отдельно от `data-theme` (день/ночь). `SET.skin` — строка, по умолчанию `'base'`, неизвестное значение из настроек или импорта → `'base'`. Поле необязательное, миграции нет.
- `theme_changed` пишется только при смене `skin`, не при переключении день/ночь.
- Шрифты скина: грузятся только при выборе скина, woff2 кладётся в отдельный кеш `NS-fonts`, не привязанный к сборке; SW его при смене версии не чистит. Базовая тема без веб-шрифтов.
- Шторка тем показывает только `free` или id из `game.owned`; платные не показываются. Старую настройку валюты `{icon,name}` в `game` не трогаем, экраны MVP её не читают.
- Выбранная тема в `rq_set`, купленные скины в `game.owned`; `appTheme` из `GAME_DEF` переносится в настройки одноразовым чтением, без повышения `schemaVersion`.
- Тест 1а: каждый `handoff/skins/*/tokens.json` содержит все обязательные имена (нет имени — ошибка, лишнее — предупреждение).
- Очередь: saveFlat → 1а → остальной этап 1 → скины (на тест только «Карандашный» бесплатно).
