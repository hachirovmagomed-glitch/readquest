### Текст Архитектора (15.10), до кода
- **`SET.flip` (15.10):** настройки листания (инверсия, тап-зоны, свайпы, кнопки). Добавочное поле, дефолт — текущие значения по умолчанию. Импорт: если не объект, поле отбрасывается и берётся дефолт. Миграция один раз при загрузке: если `SET.flip` нет, а в `SET.nav` лежит объект с листанием, а не список вкладок, этот объект копируется в `SET.flip`. `SET.nav` не удаляется и не переписывается. Если листание уже стёрто, не восстанавливается (старые данные сами не чинятся). Пишется через тот же шлюз записи, что шрифт и «Карандашный», и только из окна с замком. Функции `setSetting` пока нет, её введём в следующей волне. Новых обходов шлюза не добавлять.
- **`pos` в фоне:** на `visibilitychange` (hidden) и `pagehide` пишется последний `pos`, сохранённый до начала перетаскивания. Страница из предпросмотра ползунка не пишется никогда.
- **Переносы:** класс «переносы загружены» ставится только в DOM, в S, localStorage и экспорт не попадает.
- **`SET.flip.mode` и `SET.flip.anim` (16.10, решение Джессики «анимации и вертикальный скролл»):** два строковых поля внутри того же `SET.flip`. `mode`: `'page'|'scroll'`, умолчание `'page'`. `anim`: `'none'|'slide'|'fade'|'curl'`, умолчание `'none'` (как сейчас, мгновенно). `'curl'` («Загиб», 18.10): новая страница встаёт сразу, поверх неё отгибается копия старой размером с экран (js/page-curl.js); в прокрутке или если копию снять не вышло, анимации нет. Трекер слышит то же, что при «Нет». Значение не из списка или не строка → умолчание. Пишутся тем же шлюзом (`rqSaveSetGated`), уходят в экспорт вместе с `SET.flip`, старый файл без них даёт умолчания. Миграция из `SET.nav` эти ключи не трогает.
  - `anim` действует только при `S.ux.anim !== false` и без `prefers-reduced-motion: reduce`; само поле при этом не меняется. Анимация никогда не двигает слоем всю ленту колонок (баг 06.10): «Сдвиг» в тексте двигает ленту с главного потока без `transition`/`will-change`, «Плавно» меняет прозрачность окна `#viewer` размером с экран. В PDF анимируется только `#pdfWrap` после подмены холста. Прыжки, ползунок, «Слушать», перевёрстка не анимируются.
  - `mode='scroll'` для текста (TXT, FB2, EPUB). **18.10 (Джессика, «все 4 по очереди»): и для PDF** — `js/pdf-scroll.js`, лента страниц по ширине, «страница» = страница файла под верхней третью экрана; масштаба в прокрутке нет (зум = «Страницы»). Учёт тот же: соседняя страница после остановки = листание, дальше = прыжок, ползунок/оглавление = прыжок, «Слушать» = via:'tts'. Новых полей нет.
  - Текст: «Страница» в прокрутке = экран: `R.step` = высота окна, страница p ↔ `scrollTop = min(p·h, max)`, последняя страница = конец текста. `pos`/`ratio` считаются от номера экрана так же, как от страницы; `ratio` растёт только на остановленном экране.
  - Учёт минут в прокрутке (`reader-session.js` не меняется): отчёт идёт, когда прокрутка остановилась (~180 мс). Соседний экран = `pageTurned`+`pageShown` (как перелистывание), через два и больше = `jumped` (как ползунок, без листания). Программная прокрутка (ползунок, перевёрстка, открытие) событий не даёт. Потолок 3 мин на экран и 12 с на листание те же. Автопрокрутки нет.
- **`SET.pdfDim` (16.10, Джессика):** ползунок «Затемнение PDF» и слой `#pdfDim` убраны. Поле остаётся в данных и в экспорте (нормализация прежняя), ни на что не влияет. Ночью для PDF работает общее «Затемнение» (`SET.dim`).
- **`SET.bright`, `SET.warm`, `SET.warmNight` (18.10, Джессика «все 4 по очереди», пункт 4: своя яркость отдельно от затемнения, тёплый ночной оттенок):** три добавочных поля в SET, пишутся через `rqSaveSetGated`/`saveSet`, уходят в экспорт; старый файл без них даёт умолчания.

  - `warm`: число 0…0.6, шаг 0.05, умолчание 0. Тёплый слой `#warmer` (цвет-токен `--rq-warm`, `mix-blend-mode: multiply`) над страницей, под `#dimmer`. Без анимаций, `pointer-events: none`, только в читалке.

- Скачивание по желанию (Джессика 16.10): до кнопки «Скачать на телефон и читать · размер» ничего не качается. Файл берётся с `cache:'no-store'`, чтобы браузер не держал вторую копию; текст живёт только в IDB (ключ `text:<id>`).
- «Удалить с телефона»: удаляется только тело текста (`__rq.idb.delText` + память), через замок писателя, не под открытой читалкой. Карточка, `pathId`, прогресс и «прочитано» остаются, `rq_v1` не пишется, новых полей нет. Признак «скачана» = есть текст в памяти после загрузки из IDB при старте, нигде не хранится.
- «Скачать снова» (карточка на карте) и открытие такой книги с полки (`openBook` при `pathId` без текста) качают текст заново в ту же книгу (`__rq.idb.putText`), без новой карточки.
- Античит минут (Джессика 17.10, «слишком быстро дали опыт»): в `reader-session.js` страница, покинутая листанием или прыжком быстрее `minSec` (12 с), не даёт времени вообще (раньше давала min(dwell, 3 мин)). Последняя страница сессии и «Слушать» без порога. Отсюда минуты, XP, серия, «Ежедневка» и `bookStats.min` для карты.
- Античит карты (Джессика 17.10): процент на карте = min(позиция, засчитанные минуты `S.bookStats[id].min` / нужное время), нужное время = размер книги / 7200 байт в минуту (втрое быстрее среднего). «Прочитано» на карте = `S.finished` и не меньше 70 % этого времени. Только чтение, новых полей нет; позиция на полке и в читалке не меняется.
- Награды: только звание за главу, вычисляется из прочитанных книг, нигде не хранится. Монет и XP сверх обычных минут нет.

## 18.10: «Приключения» (бесплатные книги из открытых библиотек), поля `lang` и `srcId`
- Экран `#adv`, код `js/adv.js`, пункт «Приключения» в боковом меню (`NAV_CATALOG`, можно закрепить в нижней панели). Источники — реестр `ADV_SRC` (Викитека, Гутенберг); аудио (LibriVox) встанет туда же как `kind:'audio'`.
- Проверено 18.10 из GitHub Actions (curl с Origin): Викитека (`ru.wikisource.org/w/api.php`, `origin=*`) отдаёт поиск и текст с `Access-Control-Allow-Origin: *`; Гутенберг отдаёт с этим заголовком только OPDS-каталог (`/ebooks/search.opds`, `/ebooks/N.opds`), файлы `/cache/epub/…` — без него. Поэтому файл Гутенберга берётся напрямую (на случай, если заголовок появится), потом через `ADV_PROXY` (пока пусто, свой сервер — только по слову Джессики), иначе карточка предлагает «Скачать файл» и добавить его через «Добавить книгу».
- Викитека: скачать можно только страницу, у которой в категориях свободная лицензия (`PD-…`, `CC-…`, «Общественное достояние»). Книга = сама страница или её подстраницы по порядку ссылок (глубина ≤ 4, не больше 400 страниц), дореформенная копия (`/ДО`, `(ДО)`) пропускается, если есть современная. Шапка, номера страниц, сноски, картинки вырезаются.
- Скачанная книга идёт через `rqAddBook()` (тот же путь, что импорт файла: тело в IDB один раз, потом карточка, потом `save()`, через замок писателя). В карточке `S.userBooks[]` два поля:
  - `lang` — уже было у FB2 (код языка, `bookLang()` читает его для переносов). Здесь из каталога: Викитека `ru`, Гутенберг `dcterms:language`. Нужен и для будущей кнопки «Перевести страницу».
  - `srcId` — новое, строка `gutenberg:<номер>` или `wikisource:<страница>`. Умолчание: поля нет = обычная книга. Только для «На полке» и защиты от второй копии (повторный тап открывает уже скачанную). Импорт: карточка переносится целиком, отдельной проверки не нужно; кривое значение = книга просто не отмечается «На полке». `schemaVersion` = 1.
- Просмотр каталога и карточки ничего не пишет (ни `rq_v1`, ни `NS_set`), состояние экрана только в памяти. Монет и XP сверх обычных минут нет.
- 18.10 вечер (фикс Викитеки): категории из `action=query` приходят как `{title:'Категория:…'}`; качать можно всё, кроме страниц с отметкой о нарушении прав (у большинства старых стихов шаблона лицензии нет); списки редакций, неоднозначности и страницы авторов открываются списком; предел 800 страниц.

## 19.10: «Приключения», вторая волна (Джессика: «Давай первые 6»), поля `advWant`, `advRecent`, запись IDB `advdl:`
- Новые поля домена `library` (`LIBRARY_DEF` в `storage/schema.js`, плоско в `S`), умолчание `[]`; `schemaVersion` = 1, всё аддитивно:
  - `advWant: [{sid, page?, n?, t, a, tr?, ed?, lang?, cover?}]` (`cover` — адрес обложки Гутенберга, как в каталоге) — «Хочу прочитать»: книга из каталога, отложенная без скачивания (то, что нужно, чтобы открыть её карточку снова). Не больше 200, новые сверху. Кладётся и убирается кнопкой в карточке (один `save()`), после скачивания книга из списка убирается тем же `save()`, что добавляет книгу. Чтение: не массив → `[]`; запись без строкового `sid` вида `wikisource:`/`gutenberg:` отбрасывается при показе.
  - `advRecent: ['запрос', …]` — последние поиски, не больше 8, новые сверху, строки до 60 символов. Пишется, когда из результатов поиска открыта карточка книги (запрос оказался полезным), и кнопкой «Очистить». Чтение: не массив → `[]`, не строки отбрасываются.
  - Экспорт/импорт: поля едут в `library` обоих путей; старый бэкап без них = пусто. `hydrateLibrary` чистит: не массив → `[]`, лишнее обрезается.
- IDB, запись `advdl:<srcId>` (через `__rq.idb.put/get/del`, хранилище тел книг): недокачанная книга Викитеки `{v:1, sid, done:{страница: {s:[подстраницы]} | {t:глава, x:текст}}, ts}`. Пишется каждые ~10 страниц и при обрыве; после удачного скачивания удаляется. Не экспортируется (временная). Карточка такой книги показывает «Продолжить скачивание · N %».
- Достижения v2 (`js/ach-core.js`): статистика `libBooks` (дочитанные книги с `srcId`) и `libSrc` (из скольких библиотек), 4 записи каталога в «Книгах». Новых полей нет: считается из `S.finished` и карточек.
- Остальное (страница автора, общий поиск «Везде», «есть по-русски», книга дня) только читает каталоги и ничего не пишет.

## 19.10: «Приключения», третья волна (Джессика: «давай все»), источник `se:`, без новых полей
- `srcId`/`advWant[].sid` теперь могут начинаться с `se:` — книга Standard Ebooks (`se:<автор>/<название>[/<переводчик>]`, путь страницы на standardebooks.org без `/ebooks/`). Поля те же, `schemaVersion` = 1; `hydrateLibrary` и чтение `advWant` принимают `wikisource:`/`gutenberg:`/`se:`. Старые данные не меняются; приложение без этой правки покажет такую книгу как обычную свою (`srcId` — просто строка).
- Standard Ebooks: страницы каталога (`/ebooks?query=…&view=list`), страница книги и EPUB (`…/downloads/….epub?source=download`) отдают `Access-Control-Allow-Origin: *` (проверено 19.10 из GitHub Actions); OPDS и полные ленты закрыты (только для патронов). EPUB разбирается тем же `parseEpub`, книга ложится через `rqAddBook`, `lang` из `schema:inLanguage`.
- Прогресс по подборкам (`прочитано N из M`) и число закрытых подборок для награды `libset1` (статистика `libSet`, в `achInput` — `libSets`) вычисляются из `S.userBooks[].srcId` и `S.finished`, не хранятся.
- Фильтры (стихи/проза/пьесы, «до часа»/«длинное»), поиск по цитате (фраза в кавычках для запроса от 4 слов, отрывок из `snippet`), «Похожие книги» в карточке только читают каталоги; состояние фильтров живёт в памяти экрана.
- «Скачать все» в «Хочу прочитать»: книги по одной, каждая — обычный `rqAddBook` с тем же `save()`, что убирает её из `advWant`; обрыв оставляет скачанное, недокачанная книга Викитеки — в `advdl:`.

## 19.10: сложность книги (Джессика: «за страницу стишков и страницу философии одинаково — несправедливо»), поля `bookLvl`, `lvlPaid`, `sessions[].lvl`
- Уровни в коде (`game-awards.js` `LEVELS`): Обычная ×1 / Сложная ×1,5 / Очень сложная ×2 к опыту; бонус +5 / +10 монет за каждые 10 минут книги этого уровня за день, не больше `LVL_DAY_CAP` = 20 в день; лимит страницы 3 / 5 / 7 мин. Ежедневка +30, неделя +120 и сами минуты дня (`dayMinutes`, метрика этапа 5) не меняются.
- Включено флагом `RQ_LVL_NS` (`js/core-a.js`, сейчас только `rqt`, как достижения v2). Выключено → трекер не получает уровень, строки без `lvl`, опыт и монеты прежние.
- Уровень книги автоматический, нигде не хранится: максимум из текста (`textLevel`: доля отвлечённых и длинных слов, длина предложений; лицензия Гутенберга вырезается; меньше 1500 слов → 0), автора (`AUTHOR_LVL`: Кант, Гегель… = 2; Платон, Аристотель, Юм… = 1) и жанра файла (философия, наука = 1). PDF и сканы — только автор и жанр. Кэш в памяти по id.
- Новые поля (`schemaVersion` = 1, всё аддитивно):
  - `bookLvl: {}` (домен `progress`) — `id → 0…2`, выбор читателя. Только понижает: действует `min(авто, выбор)`, выбор выше авто не сохраняется. Пишется одним `save()` по тапу в карточке книги; выбор, равный авто, удаляет ключ. Чтение/импорт: не объект → `{}`, значения не целые 0…2 отбрасываются.
  - `lvlPaid: {}` (домен `game`) — `'YYYY-MM-DD' → монет бонуса уже выплачено за этот местный день`. Выплачивается только прирост (`applyLevelAwards`), только за дни строк, награждаемых сейчас (история задним числом не платится). Чтение/импорт: ключи только `YYYY-MM-DD`, значения целые ≥ 0.
  - `sessions[].lvl` — 1 или 2, уровень сессии (0 = поля нет). Ставит `reader-session.js` при закрытии: уровень книги на момент открытия, понижается `paceLevel`, если в среднем на перелистывание вперёд меньше 20 с (сложная) / 30 с (очень сложная) засчитанного времени при ≥ 5 перелистываниях; каждая страница идёт в среднее не больше чем 2 × порог, так что долгая стоянка на одной странице не прикрывает пролистанные. Пишется в черновик сессии и восстанавливается вместе с ним. `logSession` хранит только 1…2; импорт сессий переносит поле.
- Опыт: `xpForSession` = 10 × шаг целых минут дня × `LEVELS[row.lvl].xp`, округление. Смена уровня потом не пересчитывает выплаченное (`awardedSessionIds`, `row.xp`, `lvlPaid` как раньше).
  - `lvlText` (19.10, Джессика «Давай чтение по ПДФ») — в карточке PDF в `S.userBooks[]`: уровень 0…2 по тексту до 12 страниц (10–90 % книги, `pdfSamplePages`), `textLevel`. Ставится при добавлении PDF (пока `lvlOn()`), у старых карточек — один раз при открытии, через 1,5 с, в фоне; уровень текущей сессии поднимается `tracker.setLevel` (лимит страницы только растёт). Скан без текста = 0. Один `save()`. Если книгу закрыли до конца проверки, ничего не пишется. Чтение: не целое 0…2 → не учитывается; импорт переносит карточку целиком.
- Экспорт/импорт: `bookLvl` в `progress`, `lvlPaid` в `game`, `lvl` в строках `sessions[]`; старый бэкап без них = умолчания.
- Показ: карточка книги — раздел «Сложность» (3 кнопки, выше авто неактивны); итог сессии — строка бонуса монет и строка «Сложная книга: опыт ×1,5» или почему не начислено. Открытие карточки = 0 записей.

## 20.10: цвета цитат (Джессика: «вариативность выбора цвета», как в ReadEra), поля `quotes[].c`, `SET.hlc`
- `S.quotes[id][].c` (домен `progress`) — цвет цитаты: `'y'` жёлтый, `'g'` зелёный, `'b'` голубой, `'p'` сиреневый, `'o'` оранжевый. Нет поля или любое другое значение = жёлтый (`hlKey`, читается прощающе, назад не пишется). Красного нет (правило читалки).
- `S.hl[id]` не меняется: те же строки; цвет подсветки в книге берётся из цитаты с тем же текстом (`quoteColor`).
- `SET.hlc` (rq_set, умолчание `'y'`) — последний выбранный цвет; им сохраняют «Цитата» и «Заметка».
- Выделение внутри уже подсвеченной цитаты: цвет перекрашивает её (без второй копии), «Заметка» правит её заметку. Монеты и опыт только за новую цитату, как раньше.
- Экспорт/импорт: `c` едет внутри `quotes`, старый бэкап без него = жёлтый. Схема `schemaVersion` = 1.
