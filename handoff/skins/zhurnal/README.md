# ReadQuest — скин «Журнал» (редакционный / швейцарский)

`data-theme="zhurnal-day"` / `data-theme="zhurnal-night"`, токены `--rq-*` (`tokens.css`, `tokens.json`).
Источники: `../src/zhurnal/` (`gen_zhurnal.py` — токены, HTML, PNG, обзор; `contrast_zhurnal.py` — `contrast.tsv`).

## Стиль
- Строгая сетка с полями 24px, гротеск Golos Text 800–900 для заголовков-мастхедов, Playfair Display для крупных чисел («№ 01», «18», номера разделов 01–04, статистика).
- Тонкие линейки 1px (`--rq-rule`), 3px чернильная линейка под мастхедом. Много воздуха. Плоско: без теней, углы 0–2px.
- Никаких рисованных элементов, иллюстраций, стикеров и дудлов.
- Бумага: газетный off-white `#f5f3ee` днём, чернильно-чёрный `#141518` ночью. Один акцент: `#c4330c` днём, `#ff6b3d` ночью. Акцент только на маркере активной вкладки, основной кнопке, прогрессе/дневной полосе и ключевом числе итога.
- Обложки типографские: сплошной приглушённый цвет (6 токенов `--rq-cover-1…6` + `-ink`), крупное название 900, мелкий автор, рамка 1px.
- Библиотека нумерует книги как выпуски («№ 01»). Итог сессии свёрстан как разворот: огромное «18 минут чтения», заголовок, лид, таблица. Профиль — страница содержания с номерами разделов. Награды — чистая таблица с ценами.

## Дёшево внедрить
Только CSS-переменные, плоские цвета, бордеры и шрифты. **Без SVG-фильтров, без текстур, без картинок, без blend-mode и теней.** Обложки — `div` с фоном и текстом. Скин = `data-theme` + токены + 2 шрифта.

## Шрифты (все SIL Open Font License 1.1, полная кириллица, включая «№»)
| Шрифт | Где | Файл | Размер |

## Правила A–F
- A. Читалка плоская, PT Serif, только «34 / 210» + дневная полоса 3px акцентом. Никакого декора.
- B. Две вкладки: «01 Библиотека» / «02 Профиль». Награды — нижняя шторка из профиля (раздел 04).
- C. Без RPG в читалке. В профиле простая строка «Создать героя →».
- D. WCAG AA: `contrast.tsv`, 100 пар (50 день + 50 ночь), **0 провалов**. Мин. текст: 4.95 день (акцентное «18», проверено и как обычный текст) / 6.12 ночь (обложка 2). Мин. графика: 3.93 день / 4.32 ночь (дневная полоса vs трек). Тап-зоны ≥ 44px (вкладки 66px, фильтры 46px, кнопки покупки 44px, «В библиотеку» 56px).
- E. Итог: «+30 🪙 ежедневка выполнена» и кнопка «В библиотеку». Валюта — «монеты».
- F. Активное не только цветом: вкладка — жирный + полоса 4px сверху; фильтр — жирный + подчёркивание 3px; тир цены — жирный + подчёркивание; неделя — залитые vs контурные квадраты; неактивная кнопка покупки — контур вместо заливки.

## Файлы
10 экранов × 1x (390×844) и @2x (780×1688): library, reader, session-summary, profile, profile-rewards-sheet — day/night. `zhurnal-overview.png` (день сверху, ночь снизу). PNG всего ≈ 4.6 MB.

## Компромиссы
- В библиотеке видно 4 книги из 6 (сетка 2×N, остальное — скролл).
- Баланс монет перенесён в мета-строку под мастхедом библиотеки, отдельной плашки нет.
- Обложкам дана рамка 1px, чтобы край тёмных/светлых блоков читался на обоих фонах.
- Длинные названия на обложках вручную разбиты по строкам («Мастер / и / Маргарита»); в коде нужен `hyphens:auto` или ограничение строк.
- Шестерёнка настроек заменена текстовой ссылкой «Настройки» (в мелком размере значок выглядел как солнце).
- Тексты подсокращены, чтобы строки таблиц не переносились.
