# ReadQuest — скин «Речной отдых»

Летний день у реки: отдых, пляж на берегу. Тёплый песок, солнечно-жёлтый свет, яркий арбузно-коралловый акцент, арбузно-зелёный. Вечер — тёплый летний вечер у реки: закатное ягодное небо, тёплые «костровые» коричневые, персиково-коралловый акцент (никакого холодного синего).
Подключение: `<html data-skin="rechnoy-otdyh">` (день), `<html data-skin="rechnoy-otdyh" data-theme="night">` (вечер). Файл `tokens.rq.css` ставится ПОСЛЕ `stage1-final/tokens.css`. Legacy-селекторы `data-theme="rechnoy-otdyh-day|rechnoy-otdyh-night"` тоже работают.
Сделано 09.10.2026 (Интерфейс). Процесс и правила — как у «Речного»; внешне это другой скин: тёплая палитра, плакатная типографика, плоские фигуры вместо тонких линий.

## Файлы
- `tokens.rq.css` — подключаемый файл: канонические имена stage1-final (`--rq-*`) + extras `--rq-skin-*`. `tokens.css` — тот же файл.
- `tokens.rq.json` — структура stage1-final + `skin_extras` (здесь он лежит как `tokens.json`). `check_tokens.py`: **0 missing**, 0 extra.
- `skins-pack/13-rechnoy-otdyh/tokens.json` — исходная палитра, из неё `build_rq.py` выводит канонические токены.
- `contrast.rq.tsv` — 73 канонические пары stage1. `contrast.tsv` — проверки скина: 52 пары токенов + 132 замера по DOM готовых макетов.
- Экраны 390×844, 1x и @2x, день и вечер: `otdyh-{library,reader,session-summary,rewards,profile}-{day,night}[@2x].png` + доп. `otdyh-reader-panels-*` (читалка с панелями). Общий вид: `otdyh-overview.png` (верхний ряд — день, нижний — вечер).
- Исходники: `skins-pack/src/rechnoy-otdyh/` (копия скриптов — в `src/` рядом) — `gen_otdyh.py` (палитра → токены через `src/tokens-rq/build_rq.py` → HTML → PNG → обзор), `audit_otdyh.py` (контраст, пересечения декора, тап-зоны → `contrast.tsv`). HTML самодостаточные (вшиты stage1 `tokens.css` и `tokens.rq.css`).
  Пересборка: `cd skins-pack/src/rechnoy-otdyh && python3 gen_otdyh.py && python3 audit_otdyh.py`.

## Декор: один стиль — плоский летний плакат
Только сплошные заливки из ограниченной палитры (`--rq-skin-stripe-a/b/c`, `sun`, `melon`, `melon-flesh`, `seed`, `wood`, `wood-dark`, `ring`, `hat`, `sand`): без контуров, без градиентов внутри фигур, без фильтров и картинок.
- **Тент кафе** — полосатая маркиза с фестонами по верхнему краю экранов приложения (в полосе статус-бара, выше заголовка) и по верху карточки итога.
- **Полосы пляжного полотенца** — коралл/крем/жёлтый, верхняя кромка нижнего меню (часть меню).
- **Сценки на берегу** — только в пустом месте над меню: «Награды» — лодка с вёслами и надувной круг на песке; «Профиль» — шлёпанцы, шляпа от солнца, долька арбуза. В «Библиотеке» там полка, сценки нет.
- Мягкое солнце / тепло костра в шапке — CSS `radial-gradient` (`--rq-skin-glow`).
**В читалке декора нет вообще**, шрифт книги — из настроек; номер «98 / 185» и дневная полоса 3 px (`--rq-skin-daybar`). XP, уровня и монет в читалке нет.
Проверка `audit_otdyh.py`: 0 пересечений декора с текстом и зонами нажатия на 12 кадрах, 0 элементов декора внутри `#reader`.

## Этап 1: правила
- Три вкладки: **Библиотека / Награды / Профиль** (активная — пилюля `accent-tint` + подпись 800 `accent-text`).
- Итог сессии (как `summary-day` канона) поверх чистой читалки: «Цель дня +30 монет», «Время чтения 12 минут», «Страницы 14», **«Опыт · Уровень 4 · +120 XP»** с полосой «1 360 / 1 600 XP · до уровня 5 ещё 240 XP», «Цель дня выполнена», «Неделя: 2 из 4 дней», «В библиотеку».
- «Награды» — вкладка: задания дня (+30) и недели (+120), «Награды из жизни 3 из 5», «Обменять» / disabled с «не хватает 110 монет», «Добавить награду». Никаких замков, цен и покупок скинов.
- «Профиль»: уровень и XP, монеты, стрик, минуты за неделю, «Создать героя ›».
- Цифры канона (уровень 4, 1 240 / 1 600 XP, 390 монет, 3 дня подряд, неделя 2 из 4). Склонения через `plural()`: «390 монет», «110 монет», «3 дня подряд», «36 минут чтения», «12 минут». Эмодзи нет; валюта — иконка `coins` + «монеты». Иконки — Lucide stage1.

## Проверки
- **Контраст:** канонические 73 пары — 0 провалов (мин. текст 4.73 день — `accent-text` на `accent-tint`; 5.28 вечер; графика 4.24 / 4.39). `contrast.tsv` — 184 строки, **0 провалов**: мин. текст 4.59 день (`accent-text` на верхе солнечного градиента) / 5.28 вечер; мин. графика 3.66 день / 3.49 вечер (`border-strong` на верхе градиента). Не считались 2 disabled «Обменять» и текст под затемнением итога.
- **Тап-зоны:** 72 интерактивных элемента на 12 кадрах, все ≥ 44×44.
- Все PNG просмотрены глазами; исправлено: лодка и вёсла перерисованы (читались как палочки), долька арбуза поставлена на песок, разведены карточки профиля.

## Компромиссы
- Тент стоит в полосе статус-бара (y 0–37): на телефоне поверх него будут системные значки; при прозрачном статус-баре значки тёмные днём / светлые вечером — проверить на живом устройстве.
- Unbounded широкий: заголовки 25 px, на «Библиотеке» рядом с чипом монет помещается с запасом ~70 px; длинные заголовки (если появятся) — переносить или ужимать до 22 px.
- Акцент днём на самом светлом месте фона даёт 4.59 — проходит, но запас небольшой; не светлеть `--rq-skin-bg-top`.
