## Решения этапа 1
- Акцент бирюза `#1f6f6b` день / `#5fb8ae` ночь.
- Ночной PDF: чёрный слой поверх canvas, без инверсии. Ползунок `SET.pdfDim` 0–0.5, шаг 0.05, дефолт 0.35 (выше 0.53 чёрный текст < 4.5:1).
- Фокус: `SET.focus` `'off'|'button'|'auto'`, дефолт `'button'`; класс на `#reader`; счётчик «7 / 10 мин» (та же функция, что `mvpDailyInfo()`), на 10/10 — галочка, без тоста. Тап-зоны: верх 12% (лево — день/ночь, право — закладка `addBookmark()`), ниже 30/40/30, выход из фокуса только центром.
- Тосты `flashMsg(text,{kind})`: `game` в читалке никогда; `info` без эмодзи («Яркость N%», «Закладка на стр. N», N = `R.page+1` / `pdfLabel()`).
- Адаптив: колонка ≤680px, шторки-карточки ≤480px, сетка 3 кол. <400px / 4 кол. ≥400px, `clamp()` на rem, safe-area, тап ≥44px, поворот разрешён. Убранные настройки (анимация листания, масштаб UI) не возвращать.
- Панель читалки: Оглавление · Ночь/День · Шрифт · Фокус · Весь экран (в режиме «Выкл» — 4 кнопки).
