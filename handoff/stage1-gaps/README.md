# Этап 1 · недостающие макеты (stage1-gaps)

Базовый стиль приложения (бирюза), токены `stage1-final` без изменений: `tokens.css` скопирован из канона, `src/mock.css` и хелперы (`nav`, `library`, `profile`, `summ`, `reader`, `pdfpage`, `reader_settings`) берутся из канонического `stage1-final/src/gen.py` (лежит в `src/canon/`). Скины заморожены, здесь их нет: «Карандашная» показана только как вариант выбора.

390×844, день и ночь, 1x и @2x (`<экран>-day|night[@2x].png`). Сводка: `stage1-gaps-overview.png` (верхний ряд день, нижний ночь).
Пересборка: `cd src && python3 gen_gaps.py` (кадры + сводка), `python3 gen_gaps.py taps` (зоны нажатия), `python3 contrast_gaps.py` (контраст → `src/contrast-gaps.tsv`).

**Проверки:** контраст новых пар по каноническим токенам: 52 пары, 0 провалов (мин. текст 5.17, графика 5.42). Все интерактивные элементы новых экранов не меньше 44×44 (замер в Chrome по DOM, 0 нарушений). Склонения: «6 книг», «1 файл не открылся», «2 файла не открылись» (функции `books()`/`fails()`), «уже в библиотеке: 2», «3 из 7».

## «Вид страницы»: тема страницы и оформление приложения

Это две разные настройки, и в шторке они стоят отдельными разделами с разными подписями и разным видом карточек.

1. **«Тема страницы · только лист книги»** — как в каноне: День / Сепия / Ночь, карточки «Аа» цвета листа (`data-page` на `#reader`). Меняет только лист книги.
2. **«Оформление приложения»** — сразу под ней, с подписью «Меню и экраны вокруг книги. Страница не меняется.» Две карточки-образца: **Базовая** (выбрана, галочка) и **Карандашная**. Образец — мини-экран (шапка, карточка, кнопка) в цветах скина в текущем режиме день/ночь. У «Карандашной» неровный контур запечён в path, SVG-фильтров нет. Подпись под образцом: у выбранной `accent-text` 700, у другой `text` 500. Карточка высотой 98, вся карточка — зона нажатия (`role="radio"`).
   - Меняет `data-skin` на `<html>` (`base` | `pencil`). Ночь/день приложения по-прежнему `data-theme`, то есть Карандашная бывает и дневной, и ночной.
   - Закрытых тем, замков, цен и ссылки в магазин нет: в этапе 1 вариантов ровно два.
   - Та же настройка позже появится и в «Настройках → Оформление». Хранится одно значение.

Почему не одним рядом: в одном ряду «Ночь» страницы и «Карандашная» выглядели бы взаимоисключающими, а на деле это два независимых выбора (Карандашная + сепия и т. п.). Раздел приложения стоит вторым: тема страницы нужна чаще. Шторка стала выше (780 вместо ~704) и прокручивается, нижние разделы уходят под маску.
