# Эталонная полка сложности

`golden.test.mjs` проверяет, что `autoLevel` (текст + автор + название, как в карточке книги) ставит каждой книге ожидаемую ступень:
0 Обычная, 1 Сложная, 2 Очень сложная, 3 Экспертная, 4 Запредельная. У книги диапазон `min…max`, у некоторых ещё `txtMin` —
ступень, которую должен дать один текст без автора.

- `en-<номер>.txt.gz` — книги Project Gutenberg (общественное достояние), зеркало GITenberg на GitHub. Хранится не вся книга,
  а три куска по 19 900 знаков с 15 %, 45 % и 75 % текста — ровно то, что читает `textStats`. Номер = номер книги на Gutenberg.
- `golden.json` — название, автор, ожидаемый диапазон.
- Русские книги: встроенная полка `source/books/*.txt` (вся классика — «Обычная»). Русских сложных книг (философия, учебники,
  монографии) из облака не достать (Викитека, lib.ru и т. п. закрыты) — их добавлять с телефона/компа: положить файл,
  добавить строку в `golden.json` (`f`, `title`, `author`, `min`, `max`).

Запуск: `node golden.test.mjs`; `RQ_GOLDEN_TABLE=1` печатает таблицу (балл, уровень по тексту, итог, ожидание).
