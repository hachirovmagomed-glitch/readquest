### Текст Архитектора (15.10), до кода
- **`SET.flip` (15.10):** настройки листания (инверсия, тап-зоны, свайпы, кнопки). Добавочное поле, дефолт — текущие значения по умолчанию. Импорт: если не объект, поле отбрасывается и берётся дефолт. Миграция один раз при загрузке: если `SET.flip` нет, а в `SET.nav` лежит объект с листанием, а не список вкладок, этот объект копируется в `SET.flip`. `SET.nav` не удаляется и не переписывается. Если листание уже стёрто, не восстанавливается (старые данные сами не чинятся). Пишется через тот же шлюз записи, что шрифт и «Карандашный», и только из окна с замком. Функции `setSetting` пока нет, её введём в следующей волне. Новых обходов шлюза не добавлять.
- **`pos` в фоне:** на `visibilitychange` (hidden) и `pagehide` пишется последний `pos`, сохранённый до начала перетаскивания. Страница из предпросмотра ползунка не пишется никогда.
- **Переносы:** класс «переносы загружены» ставится только в DOM, в S, localStorage и экспорт не попадает.
- **`SET.flip.mode` и `SET.flip.anim` (16.10, решение Джессики «анимации и вертикальный скролл»):** два строковых поля внутри того же `SET.flip`. `mode`: `'page'|'scroll'`, умолчание `'page'`. `anim`: `'none'|'slide'|'fade'`, умолчание `'none'` (как сейчас, мгновенно). Значение не из списка или не строка → умолчание. Пишутся тем же шлюзом (`rqSaveSetGated`), уходят в экспорт вместе с `SET.flip`, старый файл без них даёт умолчания. Миграция из `SET.nav` эти ключи не трогает.
  - `anim` действует только при `S.ux.anim !== false` и без `prefers-reduced-motion: reduce`; само поле при этом не меняется. Анимация никогда не двигает слоем всю ленту колонок (баг 06.10): «Сдвиг» в тексте двигает ленту с главного потока без `transition`/`will-change`, «Плавно» меняет прозрачность окна `#viewer` размером с экран. В PDF анимируется только `#pdfWrap` после подмены холста. Прыжки, ползунок, «Слушать», перевёрстка не анимируются.
  - `mode='scroll'` только для текста (TXT, FB2, EPUB). PDF всегда постранично, пока не будет отдельного решения. «Страница» в прокрутке = экран: `R.step` = высота окна, страница p ↔ `scrollTop = min(p·h, max)`, последняя страница = конец текста. `pos`/`ratio` считаются от номера экрана так же, как от страницы; `ratio` растёт только на остановленном экране.
  - Учёт минут в прокрутке (`reader-session.js` не меняется): отчёт идёт, когда прокрутка остановилась (~180 мс). Соседний экран = `pageTurned`+`pageShown` (как перелистывание), через два и больше = `jumped` (как ползунок, без листания). Программная прокрутка (ползунок, перевёрстка, открытие) событий не даёт. Потолок 3 мин на экран и 12 с на листание те же. Автопрокрутки нет.
- **`SET.pdfDim` (16.10, Джессика):** ползунок «Затемнение PDF» и слой `#pdfDim` убраны. Поле остаётся в данных и в экспорте (нормализация прежняя), ни на что не влияет. Ночью для PDF работает общее «Затемнение» (`SET.dim`).
- **Тест `SET.flip`:** поменять листание, потом вкладки панели, импортировать старый файл без `SET.flip`, перезапустить. Листание на месте, `SET.nav` в экспорте не изменился.
- **«Слушать»:** счётчик «слушал N мин» — после волны 1. Сейчас только `setCounting(false)` на время чтения вслух.

## 09.10, вечер: решения после проверки сборки 2100 на Android (для 1б)
- `reader-session`: новый вызов `jumped(page)` для ползунка, оглавления и закладок. Он сбрасывает лимит страницы и НЕ трогает `pageTurns` и счётчик быстрого листания. Срабатывает один раз, когда палец отпущен; промежуточные страницы, пока тянут ползунок, событий не порождают. `pageTurned` теперь только для тапа, свайпа и клавиш.
- `page_visible` получает необязательное поле `via: 'turn' | 'jump'`. Если поля нет (старые события), считаем `'turn'`. `schemaVersion` остаётся 1.
- Минуты за день: одна функция, `Math.floor` от суммы `minutes` всех сессий за день. По ней считаются стрик (порог 2), ежедневка, неделя и «N / 10». Вторая формула запрещена. `metrics.py` должен давать те же минуты по дням; тест на одном экспорте.
- `atRisk` и подсказка про стрик приводятся к 2 минутам.
- 15.10 (решение Мани): мягкий минимум стрика поднят с 2 до 3 минут, одна константа `STREAK_MIN` в `js/core-a.js` (стрик в closeReader, `atRisk`, подсказка). Цель дня 10 мин и выплаты не меняются. Новых полей нет.
- `storage_persist` пишем только при смене `granted`, а не при каждом запуске.
- В экспортах до 1б прыжки ползунком лежат в `pageTurns`: сравнивать по номеру сборки, напрямую не смешивать.
- `metrics.py`: «фейковая» сессия — от 1 минуты без засчитанных перелистываний (правка Продукта).
- «Назад» (1б): `pushState({rq:'reader'}, '', location.href)`, адрес не меняется, без `#`. `closeReader()` идемпотентный: одна сессия, один id, одна выплата, даже если кнопка, `popstate` и `pwa-lock` сработали подряд. Кнопка «назад» в шапке вызывает `history.back()`. После F5 `popstate` с `{rq:'reader'}` при закрытой читалке ничего не делает. Порядок шагов — по `ui.md`.
- `pdf-verify`: метку страницы ищет только в прямоугольнике canvas страницы, оверлеи (плашка «ТЕСТ») не прячет.
- XP (решение Квестмастера, 1б): XP сессии = 10 × (floor(минут за день после) − floor(минут за день до)). «До» — сессии того же дня, начавшиеся раньше: сортировка по `startedAt`, при равенстве по `id`; для старых сессий без `startedAt` — порядок в `sessions[]`. XP записывается в сессию (`xp`), итог показывает записанное. Золото и квесты считаются от того же `dayMinutes`. Закрытие брошенной сессии в `begin()` идёт через тот же идемпотентный путь, что и `closeReader`, без показа итога.
- В сессию добавляются необязательные поля `startedAt` (ISO) и `xp`. `schemaVersion` остаётся 1.
