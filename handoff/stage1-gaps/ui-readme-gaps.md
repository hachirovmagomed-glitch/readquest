## Дополнение к «Пробелы, закрыть до 1б» (Интерфейс, 09.10)

- **Двойной тап в PDF.** Тап по центру в PDF ждёт второй тап 250 мс. Двойной тап при масштабе «по ширине» увеличивает страницу ×2 в точке тапа, при увеличенной странице возвращает к ширине. Одиночный тап по центру открывает панели.
- **Тап-зоны.** Края (30% слева и справа) листают сразу, без ожидания, в тексте и в PDF. В тексте у двойного тапа действия нет, поэтому тап по центру открывает панели сразу. Пока PDF увеличен, верхние 12% (день/ночь, закладка) и выход из фокуса центром отключены, свайп двигает страницу, листание тапом по краю или когда край страницы упёрся в край экрана.
- **Ноль пустых кадров.** При листании, пинче, пане, входе и выходе из полноэкранного режима и смене размера экрана нет ни одного кадра, где контейнер страницы есть, а текста нет, страница перевёрнута или подложка разъехалась с текстом. Допуск в тестах 0; ослаблять нельзя без «ок» Мани на живом телефоне.
- **Скины.** Тема меняет только интерфейс вокруг страницы (`data-theme` + токены `--rq-*`). Лист книги и PDF в любой теме без декора и шрифтом из настроек. SVG-фильтры (неровные контуры, зерно) запекаются в готовые SVG; в читалке фильтров нет.
