# ReadQuest: одежда героев — передача для разработчика

## Что это
В ReadQuest у читателя есть герой: девушка или парень. Герой носит одежду, купленную в магазине за игровую валюту. Первая вещь — толстовка с капюшоном, её можно перекрасить в 10 цветов палитры.
Скины приложения (в том числе «небесный») меняют только оформление вокруг героя: фон, рамки, свечение, токены `--rq-*`. Логику одежды и слои скины не меняют.

Требования продукта: PWA, вертикальный экран 390×844, интерфейс полностью на русском, значки Lucide (не эмодзи), акцент `#1f6f6b` днём и `#5fb8ae` ночью, без фиктивных переключателей.

## Система координат
- Все слои нарисованы на одном холсте **4096×6144** (2:3), начало координат в левом верхнем углу.
- Полноразмерные файлы (`base-girl.png`, `hoodie-girl.gray.png` и т. д.) совпадают пиксель в пиксель: их можно класть друг на друга без сдвига.
- Для приложения используйте обрезанные файлы `*.trim.png`. Рядом лежит JSON вида `{"canvas":[4096,6144],"x":834,"y":981,"w":2404,"h":2230}`: обрезку рисуют в точке (x, y) холста. На экране всё умножается на один масштаб `scale = ширина_вывода / 4096` (для ширины 390 это ≈ 0.0952).
- У толстовки один `hoodie-<who>.trim.json` на все её варианты (красный, серый, детали): обрезки одинаковые.

Смещения:

| Файл | x | y | w | h |
|---|---|---|---|---|
| base-girl.trim | 749 | 90 | 2544 | 5965 |
| base-boy.trim | 945 | 25 | 2129 | 6066 |
| hoodie-girl.*.trim | 834 | 981 | 2404 | 2230 |
| hoodie-boy.*.trim | 977 | 853 | 2081 | 2137 |

## Порядок слоёв
1. База героя (`bases/base-<who>`), прозрачный фон.
2. Одежда (`items/<вещь>/...`), перекрашенная.
3. Волосы поверх одежды отдельного слоя не имеют: там, где волосы базы лежат на капюшоне, они уже вырезаны из слоя одежды. Поэтому одежда рисуется после базы, и волосы остаются видны.

Фон и оформление скина рисуются под базой.

## Перекраска
Эталон: `web/recolor.js` (функции `recolorPixels` и `drawHero`). Демо: `web/recolor.html`. Та же формула на Python есть в `tools/sheet.py`.

На входе серый слой `hoodie-<who>.gray(.trim).png` (R=G=B — затенение, A — маска), маска деталей `hoodie-<who>.details(.trim).png` (0–255) и цвет из `palette.json`.

Для каждого пикселя, где `mid = 0.82` (средний тон ткани в сером слое):
```
s = gray/mid − 1
тело:   s<0 → C·(1 + s·contrast);   s≥0 → C + (1−C)·s·contrast·0.8
детали: D = C·detail;  s<0 → D·(1 + s·contrast);  s≥0 → D + (1−D)·s·contrast·0.5
цвет = тело·(1−m) + детали·m,  m = маска деталей / 255
цвет = lift + цвет·(1−lift)
альфа = альфа серого слоя без изменений
```
Обычный multiply не используется: белый с ним не получает света, а чёрный проваливается в сплошное пятно.

### Правила палитры (`palette.json`)
- `id` латиницей и навсегда, он хранится в профиле; `name` по-русски, его видит пользователь.
- `hex` — основной цвет; `contrast` — сила складок; `detail` — во сколько раз темнее швы и шнурки; `lift` — подъём чёрного (по умолчанию 0).
- Тёмные цвета: `contrast` 1.1–1.6, `lift` 0.04–0.08. Светлые: `contrast` 0.85–0.95, `detail` 0.7–0.8.
- Каждый новый цвет проверяйте на светлом `#faf8f4` и тёмном `#121212`: `tools/sheet.py` строит такие листы.
- Сейчас в палитре: red, navy, black, cream, forest, mustard, lavender, pink, sky, gray.

## Модель данных
Профиль хранит выбор локально, например в IndexedDB или localStorage рядом с прогрессом героя:
```json
{ "hero": "girl", "outfit": [ { "item": "hoodie", "color": "red" } ] }
```
Отдельная вещь — `{item:'hoodie', color:'red'}`. Неизвестный `color` заменяется первым цветом палитры. Пикселей в профиле нет, только идентификаторы.

## Производительность
- Перекраска попиксельная. Делайте её **один раз** при смене цвета, героя или размера, сразу в размере экрана (`scale`), а не в 4096×6144.
- Результат кешируйте: `OffscreenCanvas` или `ImageBitmap` в памяти, при желании blob в Cache Storage с ключом `hero|item|color|ширина`.
- В кадре рисуется только готовая картинка. На 390 px перекраска занимает заметно меньше секунды.
- Полноразмерные PNG в сборку PWA не нужны: хватит `*.trim.png`, при желании уменьшенных до 2× от ширины экрана (около 800 px). Полноразмерные файлы — исходники для пересборки.

## Демо
`fetch` не работает с `file://`, поэтому откройте через локальный сервер из корня пакета:
```
python3 -m http.server 8000
# http://localhost:8000/web/recolor.html?color=navy
```

## Как добавить новую вещь
1. Нарисуйте вещь на холсте 4096×6144 **в той же позе**, лучше прямо поверх `bases/orig/base-<who>.orig.png`, на белом фоне. Если рисунок другого размера (как толстовка, перерисованная в 864×1152), его совмещает `tools/reg.py`, но результат будет мягче.
2. Положите исходник в `items/<вещь>/source/` и поправьте пути и правила цвета в копиях `reg.py`, `ext.py` и `gray.py`. Сейчас `ext.py` выделяет ткань по красному цвету; для вещи другого цвета замените условие `red`.
3. Запустите сборку (`tools/rebuild.sh` или команды ниже). Получатся слой, серый слой, маска деталей, обрезки и JSON смещений.
4. Проверьте глазами `previews/preview-*`, `swatches-*` и `edges-dark.png`:
   - нигде не торчит серая база;
   - нет щелей и ореолов на `#121212`;
   - волосы лежат поверх одежды;
   - у новых героев проверьте глаза (блики не должны стать прозрачными) и щели между прядями.
5. Добавьте `id` вещи в данные магазина. Палитра общая для всех вещей.

## Пересборка
```
pip install -r tools/requirements.txt
bash tools/rebuild.sh
```
Скрипт копирует инструменты и исходники во временную папку и выполняет по порядку:
`python3 cutout.py && python3 reg.py && python3 ext.py && python3 gray.py && python3 previews.py && python3 sheet.py && python3 edges.py edges-dark.png`
Затем раскладывает результат обратно в `bases/`, `items/hoodie/` и `previews/`. Пересборка проверена: альфа слоёв совпадает с файлами пакета.

## Известные проблемы
- **Мягкость.** Толстовка перерисована в 864×1152 и увеличена примерно в 5,4 раза, поэтому в полном размере она мягче базы. На экране 390×844 этого не видно. Для резкости вещь нужно рисовать сразу в 4096×6144.
- **Маска деталей приблизительная.** Она найдена автоматически по тёмным линиям и контуру. Шнурки, манжеты и низ резинки не выделены сплошными формами, так что перекрасить их совсем другим цветом аккуратно не получится; нужна ручная маска.
- **Чёрный на деле графит** (`#2a2a2d` с `lift`), иначе складки не читаются. Сливочный имеет слегка серые тени.
- **Поиск щелей в фоне подобран под эти два рисунка** (`tools/cutout.py`): щель между прядями распознаётся по тёмному контуру волос вокруг, блик глаза — по его отсутствию. Для новых героев проверяйте глаза и пряди глазами.
- **Девушка в базе без рукавов,** с открытыми плечами; у парня футболка и шорты. Под толстовкой это не видно, но учитывайте для других вещей.
- **Вырез капюшона.** В V-вырезе видна серая база: так задумано.
- Волосы девушки вырезаны из капюшона по форме её базовой причёски. При другой причёске край капюшона под волосами будет виден.

## Правила команды
- Пуш только после «ок» Архитектора и Деуса. Никакого force push.
- Репозиторий публичный: никаких личных данных, ни в коде, ни в коммитах, ни в картинках.
- Интерфейс по-русски, значки Lucide, никаких переключателей, которые ничего не делают.
