# ReadQuest — скин «Деловой журнал» (классический деловой / финансовый журнал)

`data-theme="delovoy-day"` / `data-theme="delovoy-night"`, токены `--rq-*` (`tokens.css`, `tokens.json`).
Источники: `../src/delovoy/` (`gen_delovoy.py` — токены, HTML, PNG, обзор; `contrast_delovoy.py` — `contrast.tsv`).
Чужие названия, логотипы и фирменные шрифты изданий не используются — только общий жанр «деловой журнал».

## Чем отличается от «Журнала» (9)
«Журнал» — швейцарский гротеск, оранжевый акцент, сетка 2×N. «Деловой журнал» — контрастная антиква (didone) в заголовках и цифрах, чёрно-белая вёрстка с двойными линейками, один глубокий финансовый синий, рейтинги и «котировки».

## Стиль
- Заголовки-мастхеды и крупные цифры — Prata (didone); UI — Inter. Двойная линейка 3px+1px под шапкой.
- Ч/б + ОДИН акцент: синий `#0b3b8f` днём / `#8fb3ff` ночью (кнопки, активная вкладка, прогресс, дневная полоса, кикер «Главная тема»).
- Экономно и только с AA: денежный зелёный `--rq-up` / красный `--rq-down` — только для цифр ▲▼ (направление передаёт сам знак); золото `--rq-gold` — только значение «Состояние».
- Библиотека = «Рейтинг чтения»: #1 крупно с обложкой, #2–#5 списком; прогресс как котировка «53%» + «▲ +4% за неделю».
- Обложки — как обложки журналов: цветной блок, название антиквой сверху, линейка, автор капителью как «анонс». В списке — монограмма-мастхед. Без фото.
- Итог сессии — «главная тема номера»: «18 минут» антиквой 76px, лид, подпись, блок «В цифрах» (14 страниц / 6 дней подряд / 16% книги), строки «День ✓ +30 🪙 ежедневка выполнена» и «Неделя 2 / 4 дня», кнопка «В библиотеку».
- Профиль — карточка из «списка состояний»: имя антиквой 46px, «Состояние: 504 монеты», мини-таблица показателей с ▲▼ (подписано «к прошлой неделе · пример данных»).
- Награды — прайс-лист/портфель: колонки «Позиция / Купить», цена-кнопка, выбор цены 100 / 250 / 500.
- Ночь: настоящий тёмный `#0f0f11`, текст off-white `#f1efe9`, акцент осветлён.

## Дёшево внедрить
Только CSS-переменные, плоские цвета, бордеры и шрифты. **Без SVG-фильтров, текстур, картинок, теней и blend-mode.** Обложки — `div` с фоном и текстом.

## Шрифты (все SIL Open Font License 1.1, кириллица полная)
| Шрифт | Где | Файл | Размер |
|---|---|---|---|
| Prata Regular | заголовки, имя, «18 минут», названия на обложках | Prata-Regular.ttf | 97 KB |
| Playfair Display (только цифры, `#`, `%`, `№`) | цифры внутри той же гарнитуры `RQSerif` (`unicode-range`) | PlayfairDisplay-VariableFont_wght.ttf | 294 KB полный; сабсет цифр ≈ 5–10 KB |
| Inter (вариативный, 400–800) | весь UI, ▲▼ | Inter-VariableFont_opsz,wght.ttf | 875 KB; статичные 400/600/700 в WOFF2 с кириллицей ≈ 3×70–100 KB |
| PT Serif (уже в приложении) | текст книги в читалке | — | — |
Почему цифры не из Prata: у Prata единица выглядит как «l» («#l», «l4»), а знака «№» нет. Цифры берутся из Playfair Display Regular (тоже didone) с `lnum`.

```css
@font-face{font-family:"RQSerif";src:url(Prata-Regular.woff2)}
@font-face{font-family:"RQSerif";src:url(PlayfairDisplay-digits.woff2);unicode-range:U+0030-0039,U+0023,U+0025,U+2116}
```

## Правила A–F
- A. Читалка плоская, PT Serif, только «34 / 210» + дневная полоса 3px. Без декора.
- B. Две вкладки «Библиотека» / «Профиль». Награды — нижняя шторка из профиля.
- C. Без RPG в читалке. В профиле простая строка «Создать героя →».
- D. WCAG AA: `contrast.tsv`, 114 пар (57 день + 57 ночь), **0 провалов**. Мин. текст: 5.81 день / 7.17 ночь (номер страницы). Мин. графика: 6.48 день / 6.02 ночь. Тап-зоны ≥ 44px (вкладки 66px, фильтры 44px, кнопки покупки и тиры 44px, «В библиотеку» 56px).
- E. Итог: «+30 🪙 ежедневка выполнена» и «В библиотеку». Валюта — «монеты».
- F. Активное не только цветом: вкладка — жирный + залитая иконка + полоса 3px; фильтр — жирный + подчёркивание; тир цены — жирный + рамка; неделя — залитые vs контурные квадраты; недоступная покупка — пунктирный контур; ▲▼ — форма знака.

## Компромиссы
- В рейтинге видно 5 книг из 6 (#6 — скролл).
- Цифры подмешаны из Playfair Display (см. выше) — в коде два `@font-face` на одну гарнитуру.
- Inter тяжёлый как вариативный файл — в приложение брать статичные начертания/сабсет.
- Показатели ▲▼ в профиле — декоративные, на макете пример данных; в коде нужен расчёт к прошлой неделе (или скрыть колонку до появления истории).
- На маленьких обложках вместо названия — монограмма (полное название рядом текстом); длинные названия на большой обложке переносятся по словам.
- Обложкам дана рамка 1px, чтобы чёрная/тёмная обложка читалась на тёмном фоне.
