# Скин «Крик» (по пастели Мунка, 1893)

Макеты: `lib.png`, `read.png` (день), `lib-night.png`, `read-night.png` (ночь), 390×844 @2x. Исходники: `gen.py` + `build.py` → `*.html`. Токены — `tokens-scream.css`, значки — `icons/`.

## Мотивы
- Небо из волнистых полос мелка: днём лососевый, оранжевый, жёлтый, бледно-голубой; ночью кобальт и индиго с приглушёнными оранжевыми и кроваво-красными штрихами.
- Кобальтовый фьорд, диагональный мост с охристыми перилами, две фигуры в цилиндрах на мосту.
- Кричащая фигура — внутри кольца цели дня.
- Фактура: зернистая бумага (`feTurbulence`), штрихи мелка (`feTurbulence` + `feDisplacementMap`), неровные контуры карточек.

## Шрифты
Caveat — заголовки («Библиотека», «Моя полка», название книги, цифры цели). PT Serif — текст книги и названия книг. PT Sans — интерфейс (фишки, подписи, панели).

## Декор и интерфейс
**Декор** (только фон, не нажимается, можно отключать «Фокусом»/на слабых устройствах): небо, фьорд, мост, фигуры, завитки по краям страницы, фактура бумаги, штриховка обложек.
**Интерфейс** (берёт цвета из `--rq-*`): карточки, фишки, кольцо цели, прогресс-бары, ползунок (волнистая линия, бегунок-«солнце»), нижние панели, значки.
Правило: в зоне текста читалки — один спокойный тон без штрихов (`--rq-page-bg`), контраст текста ≥ 4.5:1 (по факту 11.7:1 днём и 13.4:1 ночью).

## Значки
Скин может подменять значки панелей. В «Крике» свои рисованные значки мелком (`icons/*.svg`: toc, night, font, focus, settings, library, profile): силуэты Lucide, но с дрожащей линией. Луна с завитком, «Профиль» — маленькая кричащая фигурка. Цвет — `currentColor`, размер 24×24.
