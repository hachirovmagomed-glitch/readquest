## 1г. Система настроек (ReadEra — навигация, Moon+ — глубина)
Макеты: `handoff/stage1-final/settings-frame/` (каркас `39dc318`, глубина `341162f`). Карта настроек: Архитектор, `/workspace/arch/settings-map.md`.
Что:
- Шестерёнка в читалке → панель чтения (вкладки Текст / Страница / Листание / Фокус, всё из `rq_set`), внизу пункт «Общие настройки».
- Экран «Общие настройки» (поля `rq_v1`: тема приложения, размер интерфейса, анимации, «не гасить экран», вибрация, язык, напоминание, данные, версия). `goal`, `anti`, `xpMult`, `autoDiff`, `devMoney` в настройки не выносим.
- Поиск по настройкам (индекс по подписям, ничего не хранит).
- «Управление»: назначение действий на зоны тапа и жесты, `rq_set.gestures` (дефолт из `nav`), «Вернуть стандартное управление» чистит только `gestures`.
- «Настройка интерфейса»: скрыть кнопки панелей, `rq_set.uiHidden` (дефолт `[]`), «Сбросить настройки интерфейса» чистит только `uiHidden`. Скрыть кнопку ≠ выключить функцию. Кольцо дня, счётчик «N / 10 мин» и монеты скрыть нельзя (выкидываются из `uiHidden` при загрузке и импорте).
Правила: `schemaVersion` = 1, поля только добавляются, проверка типа при импорте; фиктивных переключателей нет — функции без кода (TTS, словарь, яркость жестом, родительский контроль, многодокументный режим) не показываем, каждая — отдельный пункт плана; настройки не меняют начисление; любое действие дальше чем на 1 страницу помечается `via:'jump'` по самому действию, а не по жесту.
Готово, когда: все существующие настройки доступны и работают как раньше; переназначение жестов не даёт минут за прыжки (тест Квестмастера); сбросы чистят только своё поле; старый экспорт открывается; на 360 px ничего не обрезано, день и ночь совпадают с макетами; «ок» Мани.
- Шрифт и тема в панели чтения — одна строка с текущим значением, по тапу отдельный список (каждый шрифт своим начертанием, темы с образцами), идея Оскара 12.10, макеты Интерфейса.
