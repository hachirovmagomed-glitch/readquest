# Примерочная «Небесный»: слои одежды на базовых телах

Здесь лежит рабочий прототип системы кастомизации героя: 4 базовых тела (манекена) и по 8 вещей на каждом. Каждая вещь вырезана в отдельный прозрачный слой на общем холсте.

## 1. Что внутри

```
dress/
  INSTRUKTSIYA-dlya-Claude.md   ← этот файл
  tools/pipe.py                 ← скрипт выравнивания и вырезания слоёв
  tools/cfg-trousers.json       ← настройки для брюк (слот bottom до щиколоток)
  tools/cfg-malchik.json        ← брюки + серый плащ
  <body>/                       ← devushka (взрослая Ж), paren (взрослый М), devochka (подросток Ж), malchik (подросток М)
    maneken.png                 ← манекен 864×1152, белый фон
    src/<slot>.jpg|png          ← исходные генерации «манекен + одна вещь» (не выровнены)
    dressed/<slot>.jpg          ← те же генерации после выравнивания по манекену
    layers/layer-<slot>.png     ← RGBA-слой вещи на холсте 864×1152
    layers/layer-cape-back.png, layer-cape-front.png ← плащ, разрезанный на заднюю и переднюю части
    full-outfit.png             ← манекен + все слои (проверка сборки)
    full-outfit-dark.png        ← та же сборка на фоне #1a2236 (проверка ореолов)
    overview.png                ← ряд 1: примерки; ряд 2: слои на шахматке + сборки
    anchors.json                ← порядок отрисовки, холст, точки хвата, bbox слоёв
    stats.json                  ← совпадение тела до и после выравнивания по каждому слоту
```

Слоты: `headwear`, `cape`, `top`, `bottom`, `gloves`, `boots`, `main-hand`, `accessory`.

## 2. Как складываются слои

- **Холст.** У всех тел и слоёв один холст 864×1152. Фигура стоит по центру и занимает 80 % высоты (макушка y≈115, стопы y≈1035). Слои кладутся в (0,0) без сдвигов.
- **Порядок отрисовки** (`anchors.json → draw_order`):
  `cape-back → body → bottom → top → boots → gloves → cape-front → accessory → headwear → main-hand`.
  Если нет разреза плаща, весь `layer-cape.png` рисуется на месте `cape-front`.
- **body** — это `maneken.png`. Альфа тела — залитый силуэт: белый фон вокруг фигуры прозрачный.
- **Точки хвата** (`grips.main_hand`, `grips.off_hand`) — центр кисти в пикселях холста. `main_hand` — правая рука персонажа, то есть левая сторона кадра. Предметы для руки уже нарисованы в этой руке. Если рисуешь новый предмет отдельно, совмещай его рукоять с `main_hand`.
- **bbox** в `anchors.json → layers.<slot>.bbox` — это `[x0,y0,x1,y1]` непрозрачной области. Он нужен для хитбоксов, превью в инвентаре и обрезки иконок.
- **Подростки.** Тела devochka и malchik нормированы на тот же холст, что и взрослые, поэтому фигуры одной высоты. В сцене рядом со взрослыми рендерь их с масштабом **0.88** (`engine_scale`) относительно точки стоп (низ по центру). Слои подростка подходят только телу подростка.

Минимальный пример (web, canvas):
```js
const order = anchors.draw_order;           // из anchors.json
for (const k of order) {
  const img = k === 'body' ? maneken : layers[k]; // слоты, которых нет, пропускаем
  if (img) ctx.drawImage(img, 0, 0);
}
```

## 3. Перекраска

Слои сохранены в **родном цвете** вещи, без серой подложки. Рекомендации:
- Цветовые варианты делай сдвигом оттенка (hue-rotate или HSL) по маске слоя. Насыщенность и яркость не трогай, иначе пропадёт золото.
- Золото и камни (жёлтые и голубые пиксели высокой насыщенности) лучше исключить из перекраски. Простая маска: оттенок 35–60° при насыщенности больше 0.35. Альтернатива — отдельная маска «trim».
- Белые вещи (перчатки, брюки, жакет) плохо перекрашиваются через hue. Для них используй умножение на цвет (`multiply`) по слою.

## 4. Свечение и reduced-motion

Фонарь, колба с чернилами и звёзды на камнях нарисованы со статичным свечением прямо в слое. Анимированное свечение или искры добавляй отдельным слоем `fx` над `main-hand` и выключай при `prefers-reduced-motion: reduce`. Статичный слой при этом остаётся.

## 5. Известные дефекты

Слои получены из генераций и вырезаны автоматически, поэтому это прототип, а не финальный арт:
- **Генератор перерисовывает фигуру, а не правит её.** После выравнивания отклонение ≤ 1–2 px, но тонкие линии контура слегка отличаются. На тёмном фоне по краям местами видна светлая «зубчатая» кромка, особенно у плащей (paren, devushka).
- **devushka, плащ.** Плотный голубой плащ с капюшоном (перегенерирован) не совпадает по виду с полупрозрачной мантией из листа вещей. Сейчас это отдельная вещь.
- **malchik.** Кремовая пижамная рубашка и лавандовые брюки почти совпадают по яркости с телом подростка, поэтому в слоях есть дыры. Брюки вырезаны хуже всего, плащ серый на сером. Лучше перерисовать вручную или сгенерировать на контрастном теле.
- **devochka, жакет.** Белый жакет на светлом теле: остались мелкие пробелы у подола.
- **Шорты devochka.** В исходной генерации стопы стали босыми (кожа). В слой это не попало, но генерация `dressed/bottom.jpg` отличается.
- **Рука с предметом.** В слое `main-hand` есть перерисованные пальцы поверх кисти манекена. Это задумано (хват), но цвет кожи может слегка отличаться.
- **Аксессуары.** Слой очень маленький, часть контура воротника может попадать в слой.
- **Разрез плаща** на `cape-back` и `cape-front` геометрический: передняя часть — всё, что лежит поверх силуэта тела. Для открытых плащей этого достаточно. Для плащей с запахом нужна ручная маска.

## 6. Как добавить новую вещь тем же конвейером

1. Подготовь манекен нужного тела: `dress/<body>/maneken.png`.
2. Сгенерируй примерку (генератор картинок с референсом). Референс — только манекен, иногда ещё лист вещей. Соотношение 3:4. Промпт-шаблон:
   > Edit this exact image. Add only <точное описание вещи с цветами>. Keep the mannequin, its pose, face, hair, size and position exactly the same, pixel for pixel. Do not move, crop, zoom or redraw the body. Plain white background. Same anime style and soft shading. No other items, bare grey feet.

   Для предмета в руке добавь:
   > The mannequin holds <item> in its right hand (the hand on the viewer's left), fingers wrapped around the handle. The right arm stays hanging straight down as in the input.

   Частые ошибки генератора: добавляет обувь или платье «от себя» (помогает фраза «no dress, no clothing, no shoes»), перекладывает предмет в другую руку, укорачивает рукава.
3. Положи результат в `dress/<body>/src/<slot>.jpg` и запусти:
   ```bash
   pip install pillow numpy scipy opencv-python-headless
   python3 tools/pipe.py dress/<body> [--teen] [--config tools/cfg-trousers.json]
   ```
   Скрипт выравнивает генерацию по манекену (масштаб 0.94–1.06 и сдвиг по фазовой корреляции серого тела) и вырезает вещь. Вырезание — это разница с манекеном внутри области слота, очистка морфологией, эрозия 1 px и деконтаминация края. Затем скрипт пересобирает `full-outfit*.png`, `overview.png` и `anchors.json`.
4. Проверь `full-outfit-dark.png`. Если вещь выходит за типичную область слота (длинные брюки, длинный плащ), задай свою область в config: `{"roi": {"bottom": [0.40, 1.02, 28]}}` — доли высоты фигуры от макушки и порог разницы. Если вещь серая или серебряная, добавь её в `"grey_ok"`.

Совпадение тела до и после выравнивания по каждому слоту лежит в `<body>/stats.json`.
