# Скин «Алиса» (ReadQuest)

04.11.2026, тред «Внедрить скин «Алиса в Стране чудес»». Основа — пак `../strana-chudes` (10.10: палитра, контраст, макеты).
Здесь только `tokens.css` для сборки (`build-dist.sh` дописывает его в `tokens.css` приложения); декор — `source/skins/skins.css`, раздел «Алиса».

Отличия от пака:
- ключ скина `alisa` (`html[data-skin="alisa"]`), тема чтения `alisa` / `alisa-night`;
- шрифт книги не задаётся (Джессика: шрифт книги не зависит от скина), EB Garamond и Old Standard TT не берём;
- шрифты Playfair Display SC 700 и Fira Sans 500/700 лежат в `source/fonts/alisa-*.woff2`.

Мотивы — по тексту Кэрролла и манере гравюр Тенниела (общественное достояние), не по Disney:
игральные карты и масти, шахматная клетка, карманные часы Кролика, золотой ключик, чайник и чашка, пузырёк «Выпей меня», розы.
